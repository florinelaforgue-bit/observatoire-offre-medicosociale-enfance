# Architecture du logiciel

## Objectif

L'observatoire est construit selon une architecture modulaire.

Chaque module possède une responsabilité unique et ne doit pas empiéter sur les responsabilités des autres modules.

L'objectif est de garantir :

- la maintenabilité du logiciel ;
- la reproductibilité des analyses ;
- la facilité d'évolution du projet ;
- la réutilisation des composants.
